# Ifeoluwa Olatunde — Portfolio

Personal portfolio site. Static HTML, CSS and JavaScript, no build step.

- `index.html` — the landing page (loader, scroll-pinned sections, case studies, experience, contact)
- `assets/` — case study images

## Run locally

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy

Hosted on Vercel. Every push to `main` deploys to production.

## Your links

Email, LinkedIn and CV links are set at the top of the script in `index.html` (`const LINKS = { … }`). Leave one empty and its buttons show "Coming soon".
